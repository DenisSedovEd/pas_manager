Ваш личный сейф для паролей прямо в Telegram! 🔐

Этот бот помогает безопасно хранить логины и пароли от ваших сервисов, используя сквозное шифрование (AES-256).

Важно: Ваши пароли шифруются на основе вашего Мастер-пароля. Мы не храним его и не имеем доступа к вашим секретам. Не забывайте свой Мастер-пароль!

Нажмите «/start», чтобы начать работу. 🚀
